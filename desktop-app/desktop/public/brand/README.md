# Approved ZEVQORA brand assets

This Premium v0.1 package contains brand artwork extracted directly from the approved ZEVQORA brand board supplied in the project conversation.

Files used by the desktop renderer:

- `zevqora-mark.png` — approved soft-blue Z mark
- `zevqora-wordmark.png` — approved modern ZEVQORA wordmark
- `zev-mascot.png` — approved Zev puppy mascot, prepared with transparent outer background
- `zev-avatar.png` — approved Zev avatar crop
- `zevqora-lockup-light.png` — light board lockup crop
- `zevqora-lockup-dark.png` — dark board lockup crop

Do not replace these with generated/random logos, different blues, different mascot species, or a serif ZEVQORA wordmark.
