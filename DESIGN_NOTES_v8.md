# ZEVQORA Huslen Super Refresh v8

This is intentionally **not a replacement of Huslen's v7 design**.

Base retained:
- v7 page structure and browser-like chrome
- v7 hero/product composition
- v7 product dashboard visual
- v7 Zev/evidence sections
- v7 auth and billing backend wiring
- v7 transitions and interaction code

Upgrades added:
- smaller, more product-led hero hierarchy
- exact ZEVQORA Soft Blue / Ink brand alignment
- unified sans typography across web + desktop
- removed desktop Georgia/Times settings heading
- removed italic "thinking" UI treatment
- subtle initial loader + scroll progress
- restrained pointer light + product parallax
- higher quality spacing, radii, shadows and responsive behavior
- conversion-focused hero copy without fake customer/traction claims
- explicit desktop-first / replay+eval / human-review product principles
- current desktop-app source included from production v1.0.6

The existing authentication, Supabase, Stripe, download and desktop product behavior is not intentionally rewritten by the design layer.
