## spend_skipped (combined-run optimizer failure)

Root cause (code, not timing luck): the calibrate and full-replay stages are
time-sliced (`STAGE_SLICE_MS`). On a loaded machine the first slice can skip
paid plans for the spend budget (it records the reason on each plan) and then
return a continuation; later slices never revisit those plans, so the final
response's `budget` lacked `spend_skipped`. Reproduced deterministically with a
test-only slice hook (one plan step per slice) before the fix; fixed by
rebuilding `spend_skipped` from persisted plan state at the end of each stage.
Regression test: `plan-search-compute` "61b".
